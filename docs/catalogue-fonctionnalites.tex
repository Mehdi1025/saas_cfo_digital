\section{Identité produit}

FinFlow (également présenté sous la marque \emph{Mini CFO Digital}) est une plateforme SaaS destinée aux PME. Elle combine deux piliers :

\begin{enumerate}[leftmargin=*]
    \item \feat{Mini CFO Digital} — saisie mensuelle de données financières, KPI (CA, charges, marge, CAC, LTV), alertes automatiques et insights IA sur la santé de l'entreprise.
    \item \feat{FinFlow Facturation} — cycle commercial complet : clients, catalogue, devis, factures, avoirs, paiements, PDF, e-mails, tracking et tableau de bord de trésorerie.
\end{enumerate}

\section{Architecture technique}

\centering
\caption{Couches logicielles}

\bottomrule
\end{tabular}
\end{table}

\section{Acteurs et rôles}

\begin{description}[leftmargin=3cm, style=nextline]
    \item[Visiteur] Accède à la landing page, peut discuter avec l'assistant commercial IA (limité).
    \item[Utilisateur abonné] Accède au dashboard CFO, à la facturation FinFlow, au copilote IA et au profil.
    \item[Administrateur] Accède au panneau admin : gestion utilisateurs, MRR, suspension, édition des insights IA.
    \item[Client externe] Reçoit devis/factures par e-mail (PDF) ; déclenche le pixel de tracking à l'ouverture.
\end{description}

\section{Middleware et contrôle d'accès}

\begin{itemize}[leftmargin=*]
    \item \texttt{auth} — authentification Laravel Breeze obligatoire.
    \item \texttt{verified} — adresse e-mail vérifiée pour les routes sensibles.
    \item \texttt{active.subscription} — abonnement Stripe \texttt{active} ou \texttt{trialing}, compte non suspendu.
    \item \texttt{admin} — rôle administrateur (\route{/admin}).
    \item \texttt{throttle} — limitation de débit sur chat IA (12/min landing, 20/min dashboard/copilote) et webhooks Stripe (60/min).
    \item CSRF — protection sur tous les formulaires ; exception \route{POST /stripe/webhook}.
\end{itemize}

\section{Dashboard principal (\route{/dashboard})}

Contrôleur \ctrl{DashboardController} — page \texttt{Dashboard.jsx} :

\begin{itemize}[leftmargin=*]
    \item \feat{KPI mensuels} — CA, charges totales, marge nette, CAC (coût d'acquisition client), LTV (valeur vie client).
    \item \feat{Graphique d'évolution} — série temporelle CA/charges sur tous les mois saisis.
    \item \feat{Alertes automatiques} — calculées par \svc{FinancialService::buildAlert()} :
    \begin{itemize}
        \item Marge négative $\rightarrow$ niveau \texttt{critique}.
        \item LTV $<$ CAC $\rightarrow$ niveau \texttt{critique}.
        \item Charges $>$ 70\,\% du CA $\rightarrow$ niveau \texttt{attention}.
        \item LTV/CAC $>$ 3 avec marge positive $\rightarrow$ niveau \texttt{sain}.
    \end{itemize}
    \item \feat{Insight IA mensuel} — généré automatiquement par \svc{AiInsightService} via \svc{GroqApiService} ; stocké en base (\model{AiInsight}) ; contenu éditable par l'admin.
    \item \feat{Widget chat dashboard} — \texttt{DashboardChatWidget.jsx} appelle \route{POST /dashboard/chat}.
\end{itemize}

\section{Saisie mensuelle (\route{/saisie-mensuelle})}

Page \texttt{FinancialEntry.jsx} — formulaire de saisie :

\begin{itemize}[leftmargin=*]
    \item Champs : mois (\texttt{Y-m}), chiffre d'affaires, charges, budget marketing, nombre de clients.
    \item Pré-remplissage avec le dernier enregistrement (\model{FinancialRecord}).
    \item Enregistrement via \route{POST /financial-records} (\ctrl{FinancialRecordController}) — upsert par mois.
    \item API JSON \route{GET /mes-enregistrements-financiers} — liste tous les enregistrements de l'utilisateur.
\end{itemize}

\section{Formules de calcul (\svc{FinancialService})}

\begin{align*}
\text{marge\_nette} &= \text{revenue} - \text{charges} \\
\text{CAC} &= \frac{\text{marketing\_budget}}{\text{clients\_count}} \quad (\text{si clients\_count} > 0) \\
\text{LTV} &= \frac{\text{revenue}}{\text{clients\_count}} \quad (\text{si clients\_count} > 0)
\end{align*}

\section{Gestion des devis}

Routes préfixe \route{/devis} — contrôleur \ctrl{DevisController} :

\subsection{Liste et filtres (\route{GET /devis})}

Page \texttt{Devis/Index.jsx} :
\begin{itemize}[leftmargin=*]

    \item Filtres : recherche (référence ou nom client), statut, plage de dates (\texttt{this\_month}, \texttt{last\_month}, \texttt{last\_90\_days}), tranche de montant (\texttt{under\_5000}, \texttt{5000\_15000}, \texttt{over\_15000}).

    \item Pipeline visuel : brouillon / envoyé / accepté / refusé / expiré avec montants.
    \item Alertes : devis expirant dans les 7 jours (top 3).
\end{itemize}

\subsection{Création et édition}

\begin{itemize}[leftmargin=*]
    \item \route{GET /devis/nouveau} — éditeur \texttt{Devis/Create.jsx}.
    \item \route{POST /devis} — création brouillon avec numérotation auto \texttt{DEV-AAAA-NNNN} (\svc{ReferenceGeneratorService}).
    \item \route{GET /devis/\{devis\}/edit} — édition si statut \texttt{draft} uniquement.
    \item \route{PUT /devis/\{devis\}} — mise à jour brouillon ; recalcul TVA côté serveur.
    \item \route{DELETE /devis/\{devis\}} — suppression si brouillon.
\end{itemize}

\subsection{Champs du devis}

\begin{itemize}[leftmargin=*]
    \item Client (\model{Tier}), titre projet, dates émission/validité, conditions de paiement.
    \item Devise (\texttt{EUR}, \texttt{USD}, \texttt{GBP}, \texttt{CHF}) avec taux figé (\svc{ExchangeRateResolver}).
    \item Type prestation : \texttt{service} ou \texttt{produit} (avec destination logistique et jours de stockage).
    \item Options : signature en ligne (\texttt{online\_signature}), suivi d'ouverture (\texttt{open\_tracking}).
    \item Lignes : article catalogue, quantité, prix HT, remise (\% ou fixe), TVA recalculée selon pays client.
    \item Aperçu live des totaux HT/TVA/TTC côté React (\texttt{documentTotals.js}, \texttt{ligneAmounts.js}).
\end{itemize}

\subsection{Cycle de vie (machine à états)}

\begin{center}
\begin{tabular}{@{}lll@{}}

\subsection{Génération d'avoir}

    \item Crée un document \texttt{avoir} brouillon \texttt{AVO-AAAA-NNNN} lié par \texttt{parent\_id}.
    \item Copie intégrale des lignes (snapshot prix/TVA).
    \item Un seul avoir par facture ; événement \texttt{VOIDED} sur la facture source.
\end{itemize}
